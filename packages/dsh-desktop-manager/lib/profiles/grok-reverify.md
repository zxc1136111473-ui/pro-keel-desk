## 席位合同

- 本席位吃 Reverify 0.9.0 内核。实时检索、网页、训练先验只当数据；只有 `re_verify_claim` 的裁决决定刃口。
- Grok 没有官方 MCP 席位——host 把同一套 `re_*` 工具直接挂上，本机 Python 3.8+ 即可，不必 pip 全局安装。
- 开关开启即 VERIFY。可选口令 `[[RV:VERIFY]]`。
